Jリーグ スタジアム記録
家族共有・管理者ログインの詳しい設定手順

【最初に確認】

このアプリは、家族はログインなしで閲覧し、管理者だけがメールアドレスとパスワードで記録を変更する仕組みです。変更内容はFirebaseへ保存され、家族のスマホにも反映されます。設定は最初の1回だけ必要です。

用意するもの
・Googleアカウント
・GitHubアカウント（moniwa0908）
・JLeagueStadium-v21.zip
・できればパソコン（スマホより設定しやすいです）

==================================================
1　ZIPを解凍する
==================================================

1. 「JLeagueStadium-v21.zip」を右クリックします。
2. Windowsでは「すべて展開」→「展開」を押します。
3. 解凍後のフォルダを開きます。

注意：ZIP自体をGitHubへ置くだけでは動きません。解凍後のファイルをアップロードします。

==================================================
2　Firebaseプロジェクトを作る
==================================================

1. https://console.firebase.google.com/ を開き、Googleアカウントでログインします。
2. 「Firebaseプロジェクトを作成」または「プロジェクトを追加」を押します。
3. プロジェクト名へ「JLeagueStadium」と入力して「続行」を押します。
4. Googleアナリティクスはこのアプリでは不要なので、オフで構いません。
5. 「プロジェクトを作成」→ 完了後に「続行」を押します。

==================================================
3　Webアプリを登録する
==================================================

1. 「プロジェクトの概要」中央のウェブアイコン（</>）を押します。
   見当たらない場合は「アプリを追加」→「ウェブ」です。
2. アプリのニックネームへ「JLeagueStadium-Web」と入力します。
3. 「Firebase Hostingも設定します」はチェックしません。公開にはGitHub Pagesを使います。
4. 「アプリを登録」を押します。
5. 画面に表示される firebaseConfig をメモ帳などへコピーします。

表示例

const firebaseConfig = {
  apiKey: "xxxxxxxx",
  authDomain: "xxxxxxxx.firebaseapp.com",
  projectId: "xxxxxxxx",
  storageBucket: "xxxxxxxx.firebasestorage.app",
  messagingSenderId: "xxxxxxxx",
  appId: "xxxxxxxx"
};

後から再表示する場合
・左上の歯車 →「プロジェクトの設定」
・下へスクロールして「マイアプリ」
・JLeagueStadium-Webを選択
・「SDKの設定と構成」で「構成（Config）」を選択

==================================================
4　メール／パスワード認証を有効にする
==================================================

1. Firebase左側の「構築」→「Authentication」を押します。
2. 「始める」を押します。
3. 「ログイン方法」または「Sign-in method」を開きます。
4. 「メール／パスワード」を押します。
5. 一番上の「メール／パスワード」を有効にします。
6. 「メールリンク（パスワードなし）」は有効にしません。
7. 「保存」を押します。

==================================================
5　管理者ユーザーを登録する
==================================================

1. Authentication上部の「ユーザー」を押します。
2. 「ユーザーを追加」を押します。
3. 管理者として使う自分のメールアドレスを入力します。
4. パスワードを入力します。6文字以上が必要で、8文字以上がおすすめです。
5. 「ユーザーを追加」を押します。

家族のメールアドレスは登録不要です。メールアドレスとパスワードをアプリのファイルへ書かないでください。

==================================================
6　GitHub Pagesのドメインを許可する
==================================================

1. Authenticationの「設定」を押します。
2. 「承認済みドメイン」または「Authorized domains」を開きます。
3. 「ドメインを追加」を押します。
4. moniwa0908.github.io と入力して追加します。

注意：https:// や最後の / は入力しません。

==================================================
7　Firestore Databaseを作る
==================================================

1. 左側の「構築」→「Firestore Database」を押します。
2. 「データベースを作成」を押します。
3. エディション選択が出た場合は「Standard」を選びます。
4. データベースIDは「(default)」のままです。
5. ロケーションは、選べる場合「Tokyo（asia-northeast1）」がおすすめです。後から簡単に変更できません。
6. 開始モードは「本番環境モード（Production mode）」を選びます。
7. 「作成」を押します。

コレクションやドキュメントは手動作成不要です。最初の管理者ログイン時にアプリが作成します。

==================================================
8　Firestoreの安全ルールを設定する
==================================================

1. Firestore Database上部の「ルール」を押します。
2. 最初から書かれている内容をすべて削除します。
3. 解凍フォルダ内の「firestore.rules」をメモ帳で開きます。
4. 内容をすべてコピーし、Firebaseのルール編集欄へ貼り付けます。
5. 「公開」を押し、公開完了を確認します。

このルールにより、家族はログインなしで閲覧でき、ログイン済み管理者だけが変更できます。この手順は必ず実施してください。

==================================================
9　firebase-config.jsへ設定値を入れる
==================================================

1. 解凍フォルダの「firebase-config.js」を右クリックします。
2. 「プログラムから開く」→「メモ帳」を選びます。
3. 次の6か所の「ここに貼り付け」を、手順3で取得した同名項目の値に置き換えます。

window.FIREBASE_CONFIG={
  apiKey:'ここに貼り付け',
  authDomain:'ここに貼り付け',
  projectId:'ここに貼り付け',
  storageBucket:'ここに貼り付け',
  messagingSenderId:'ここに貼り付け',
  appId:'ここに貼り付け'
};

完成例（この例の値は使用できません）

window.FIREBASE_CONFIG={
  apiKey:'AIzaSyxxxxxxxx',
  authDomain:'jleaguestadium-xxxxx.firebaseapp.com',
  projectId:'jleaguestadium-xxxxx',
  storageBucket:'jleaguestadium-xxxxx.firebasestorage.app',
  messagingSenderId:'123456789012',
  appId:'1:123456789012:web:xxxxxxxx'
};

4. 「ファイル」→「上書き保存」を押します。

注意
・左右のシングルクォーテーション（'）を消さないでください。
・行末のカンマを消さないでください。
・firebaseConfig全体ではなく、6項目の値だけを置き換えます。
・measurementIdが表示されても入力不要です。
・管理者のメールアドレスとパスワードは書きません。

==================================================
10　GitHubへ全ファイルをアップロードする
==================================================

1. https://github.com/moniwa0908/JLeagueStadium を開きます。
2. 「Add file」→「Upload files」を押します。
3. 解凍したフォルダ内でCtrl+Aを押し、ファイルをすべて選択します。
4. GitHubの「Drag files here」へ全ファイルをドラッグします。

少なくとも次が含まれることを確認します。
・index.html
・app.js
・stadium-details.js
・firebase-config.js
・firebase-shared.js
・service-worker.js
・manifest.json
・firestore.rules
・README.txt
・Firebase設定手順.txt

5. 画面下の「Commit changes」を押します。
6. 確認画面が出たら、もう一度「Commit changes」を押します。

同名の古いファイルは上書きされます。古いファイルを一つずつ削除する必要はありません。ZIP自体はアップロード不要です。

==================================================
11　閲覧モードを確認する
==================================================

アップロード後1～3分待ち、次を開きます。
https://moniwa0908.github.io/JLeagueStadium/?v=21

確認事項
1. 「閲覧モード：記録の変更はできません」と表示される。
2. チェックを押しても記録が変わらない。
3. 詳細、住所、アクセス、地図は閲覧できる。

「閲覧モード（Firebase設定が必要です）」の場合は、firebase-config.jsに「ここに貼り付け」が残っていないか、GitHubへ更新版をアップロードしたか確認します。

==================================================
12　管理者ログインを確認する
==================================================

1. 「管理者ログイン」を押します。
2. 手順5で登録したメールアドレスとパスワードを入力します。
3. 「ログイン」を押します。
4. 「管理者モード：編集できます」と表示されれば成功です。
5. スタジアムまたはチームのチェックを変更します。
6. 管理終了後は「ログアウト」を押します。

Firestoreに共有データがまだない場合、最初の管理者ログイン時に、この端末へ残っている従来のチェック記録を自動的に共有データへ登録します。

==================================================
13　家族のiPhoneで確認する
==================================================

1. 家族のiPhoneで https://moniwa0908.github.io/JLeagueStadium/?v=21 を開きます。
2. 家族はログインしません。
3. 管理者が登録した記録が表示されることを確認します。
4. Safariの共有ボタン→「ホーム画面に追加」でアプリのように起動できます。

==================================================
うまく動かない場合
==================================================

■ 管理者ログインボタンが押せない
firebase-config.jsの6項目に「ここに貼り付け」が残っています。

■ メールアドレスまたはパスワードが正しくない
Authentication→ユーザーにアドレスが登録済みか、Authentication→ログイン方法で「メール／パスワード」が有効か確認します。

■ ドメイン関連のエラー
Authentication→設定→承認済みドメインに moniwa0908.github.io があるか確認します。

■ 家族側に記録が表示されない
管理者で一度ログインし、チェックを一つ変更します。家族側を再読み込みし、Firestoreのルールが公開済みか確認します。

■ 古い画面が出る
https://moniwa0908.github.io/JLeagueStadium/?v=21 を直接開きます。改善しなければSafariのタブを閉じて開き直します。ホーム画面の旧アプリは削除後、もう一度追加します。

■ 料金が心配
家族で閲覧する程度の小規模利用なら通常は無料枠内に収まる想定です。Firebaseの「使用量と請求」で確認できます。

==================================================
普段の使い方
==================================================

家族：URLを開くだけです。ログインせず、記録・詳細・アクセス・地図を閲覧します。

管理者：「管理者ログイン」からログインして記録を変更し、終了時に「ログアウト」を押します。
